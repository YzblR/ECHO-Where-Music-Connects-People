# ECHO: Where Music Connects People

ECHO is a Flutter social music application designed to connect people through music. It provides a space where users can explore music-related content, discover other users, and interact with music posts.

## Features

* Login Screen
* Home Feed
* Search and Discover
* Create Post
* Post Screen
* User Profile
* Messaging
* Music-related posts
* Likes and comments
* Bottom navigation
* Device Preview for development and testing

## Technologies Used

* **Flutter**
* **Dart**
* **Visual Studio Code**
* **Git and GitHub**
* **Device Preview**

## Getting Started

### Prerequisites

Make sure Flutter is installed on your computer.

Check your Flutter installation by running:


flutter doctor


### Installation

1. Clone the repository:

git clone https://github.com/YzblR/ECHO-Where-Music-Connects-People.git


2. Open the project folder:

cd ECHO-Where-Music-Connects-People


3. Install the project dependencies:

flutter pub get


4. Run the application in Chrome:

flutter run -d chrome
